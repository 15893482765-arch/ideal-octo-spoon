# 沁爽饮料 员工管理制度（销售外勤篇）

- 文档编号：QS-POL-HR-002
- 版本：V1.1
- 生效日期：2026-01-01
- 归口部门：人力资源部 / 销售运营部
- 适用系统：沁爽分销平台「工作台」「巡访」「绩效」模块

---

## 1. 适用范围与角色体系

本制度适用于销售体系全体员工及平台使用者。平台角色与定位：

| 角色 | 定位 | 主要工作 |
|---|---|---|
| 业务员（SALES_REP） | 一线销售 | 商家开发与维护、巡访、补货跟进、合同与活动执行 |
| 片区经理（REGIONAL_MANAGER） | 区域管理 | 排班与派单、审批（合同/排班发布等）、异常巡访判定、绩效辅导 |
| 督导（SUPERVISOR） | 运营督导 | 跟访检查、问题整改下发与复核、陈列标准落地 |
| 财务（FINANCE） | 职能支持 | 应收与押金台账、利润报表、审批财务条款 |
| 系统管理员（SYSTEM_ADMIN） | 平台管理 | 账号与权限、基础数据、系统配置 |

## 2. 账号与权限管理

1. 账号实人实名，一人一号，禁止共用、借用账号；
2. 权限按角色最小化分配，数据范围（片区/品牌）由系统按岗位自动限定，
   员工只能查看权限范围内的数据；
3. 离职或调岗当日由系统管理员停用或调整账号权限；
4. 连续 90 天未登录的账号自动冻结，需申请解冻；
5. 员工对平台内商家信息、价格政策、经营数据负有保密义务，
   禁止导出后外传。

## 3. 考勤与外勤管理

1. 外勤以**巡访任务**为基本考勤载体：到店签到、离店签退，
   系统记录定位与时间；
2. 签到定位与商家地址偏差超过阈值，或关键照片缺失的巡访记录，
   进入「异常待判定」（ABNORMAL_PENDING），由片区经理在 3 个工作日内
   判定有效或无效；
3. 判定无效（ABNORMAL）的巡访不计入覆盖率与绩效；
4. 每日工作以平台「工作台」任务清单为准，禁止无任务外勤。

## 4. 巡访工作要求

### 4.1 任务来源

- **周排班（WEEKLY_SCHEDULE）**：片区经理每周发布排班，
  覆盖责任商家，是巡访主渠道；
- **临时任务（AD_HOC）**：突发事项临时下发；
- **整改复查（RECTIFICATION）**：问题整改后的复查巡访；
- **督导跟访（SUPERVISION）**：督导陪同或抽查，**不计入业务员覆盖率**。

### 4.2 现场工作要求

到店后须完成：陈列检查并登记陈列合格率（display_pct）、冰柜状态
检查（正常/未见/断电/脏乱/破损五态）、库存与补货需求确认、
拍照留档，并给出当日结论：

- 正常（NORMAL）；
- 需要补货（NEEDS_REPLENISHMENT）→ 系统联动补货复核任务；
- 需要整改（NEEDS_RECTIFICATION）→ 生成问题整改任务；
- 风险商家—建议终止合作（PROPOSE_TERMINATION）→ 触发风险处置流程。

### 4.3 时效要求

- 巡访记录须当日提交，隔日补录需片区经理说明；
- 任务逾期（OVERDUE）自动升级提醒片区经理；
- 连续两周出现任务逾期的业务员，列入片区辅导名单。

## 5. 任务与协同

平台任务类型包括：巡访计划、合同续签复核/评估/验证、冰柜撤回/验收/
押金退还、补货复核、问题整改与复核、督导整改、活动样品回收、
风险处置等。要求：

1. 任务责任到人，同一对象同一事项系统幂等去重，不得重复建单；
2. 任务完成后须关联完成凭证（单据、照片或系统记录），
   禁止无凭证关闭任务；
3. 跨角色协同任务（如续签双线确认）双方各持一条，各自闭环。

## 6. 绩效管理

绩效按月在平台「绩效预估」中可查，主要口径：

| 指标 | 说明 |
|---|---|
| 巡访完成率 | 有效巡访任务完成数 / 计划数（督导跟访不计入） |
| 陈列合格率 | 巡访登记陈列合格率的达标商家占比 |
| 任务及时率 | 含补货复核、整改、冰柜任务的按期闭环率 |
| 进货达成 | 责任商家进货量达成情况 |

- 异常巡访、无凭证任务一律不计入绩效；
- 对绩效数据有异议，可在月度锁定前向片区经理提出复核。

## 7. 奖惩与纪律

- 虚报巡访（定位造假、照片复用）一经查实，当月绩效清零并通报；
- 泄露平台数据、私改商家资料绕过审批，按严重违纪处理；
- 陈列改善显著、风险发现及时、续签率领先的员工，
  月度评优并给予奖励。

## 8. 常见问题（FAQ）

**Q：为什么我跟着督导去巡访，覆盖率没涨？**
A：督导跟访（SUPERVISION 来源）按口径不计入业务员覆盖率，
避免重复计算；覆盖率以周排班、临时与整改任务的有效完成为准。

**Q：巡访时手机没信号，定位异常被判异常怎么办？**
A：保留到店照片（含门头和店内陈列），在异常待判定期间向片区经理
说明情况，经理可人工判定为有效。

**Q：当天没来得及提交巡访记录能补吗？**
A：隔日可补录，但需片区经理在系统内说明原因；超过 3 天的补录
不计入绩效。

**Q：任务太多完不成会被处罚吗？**
A：任务量由排班与业务规则自动分配，确属不合理的可在到期前向片区
经理申请调整；无故逾期才会触发升级与辅导机制。

**Q：能看到其他片区的商家数据吗？**
A：不能。平台按岗位限定数据范围，越权访问会被系统直接拒绝并留痕。
