# 沁爽饮料 冰柜维修与保养规范

- 文档编号：QS-POL-FREEZER-003
- 版本：V1.2
- 生效日期：2026-01-01
- 归口部门：销售运营部 / 设备管理组
- 适用系统：沁爽分销平台「冰柜」模块、巡访表单

---

## 1. 资产生命周期

每台冰柜在系统中按状态机流转，全程留痕：

```
在库 IN_STOCK → 已预留 RESERVED → 已投放 DEPLOYED
   → 待撤回 PENDING_PICKUP → 待验收 PENDING_ACCEPTANCE
   →（在库 IN_STOCK / 维修中 REPAIRING / 报废 SCRAPPED）
```

- 创建投放单即预留设备（RESERVED），现场投放完成后转为已投放；
- 撤回任务下发后转为待撤回，现场回收后转为待验收；
- 仓库验收决定去向：完好回库、送修或报废；
- **报废（SCRAPPED）为不可逆终态**，操作前须双人复核。

## 2. 投放与押金

1. 冰柜投放必须以生效合同为前提，合同中须含冰柜投放条款；
2. 投放时向商家收取设备押金，系统登记「押金收缴」流水
   （DEPOSIT_COLLECTED）并关联投放单；
3. 押金标准按柜型执行：单门柜 500 元/台，双门柜 800 元/台，
   卧式冷柜 1000 元/台；
4. 商家须签署《冰柜使用保管协议》，明确日常保管责任。

## 3. 日常保养（商家侧）

业务员巡访时应向商家宣讲并检查以下保养要求：

1. **保持通电**：冰柜须 24 小时通电运行，严禁断电存放私人物品；
2. **定期清洁**：每周清洁柜体内外，保持玻璃门与灯箱洁净；
3. **规范陈列**：只陈列沁爽品牌产品，按先进先出摆放，
   不得陈列竞品或杂物；
4. **放置环境**：避免阳光直射与紧贴热源，背部离墙 ≥10cm 保证散热；
5. **温度检查**：冷藏柜 0–4℃，发现不制冷、异响、结冰过厚立即报修。

## 4. 巡访检查与上报

巡访表单中冰柜状态为必查项，五态如实登记：

| 状态 | 含义 | 处理要求 |
|---|---|---|
| 正常（NORMAL） | 运转与陈列正常 | 无需处理 |
| 现场未见（ABSENT） | 冰柜不在店内 | 立即核实去向，涉嫌私自转移的上报片区经理 |
| 断电未插电（POWERED_OFF） | 未通电运行 | 现场恢复通电并宣教，次日复查 |
| 脏乱未清理（DIRTY） | 卫生不达标 | 现场督促清洁，必要时下发整改 |
| 破损故障（DAMAGED） | 损坏或不制冷 | 按第 5 节报修流程处理 |

## 5. 报修与维修流程

1. **报修**：业务员或商家发现故障后，在系统「冰柜」详情页发起报修，
   描述故障现象并附照片；
2. **派单**：设备管理组 1 个工作日内派单给签约维修服务商；
3. **维修**：维修开始登记 REPAIR_START，冰柜转为「维修中
   （REPAIRING）」状态；修复后登记 REPAIR_END 恢复投放状态；
4. **时限**：城区 48 小时内上门，乡镇 72 小时内上门；
   一般故障当次修复，需更换压缩机等大件的 7 个工作日内完成；
5. **费用**：质保期内非人为损坏免费维修；人为损坏（撞击、私自拆改、
   进液）维修费用由商家承担，从押金中抵扣；
6. **超龄设备**：服役满 8 年或年度维修超过 3 次的冰柜，
   由设备管理组评估后走报废流程。

## 6. 撤柜与验收

1. 合同终止、商家闭店或策略调整时，系统下发「冰柜撤回」任务
   （FREEZER_RECALL），业务员按任务上门回收；
2. 现场回收（PICKUP）后冰柜转为「待验收
   （PENDING_ACCEPTANCE）」，须在 5 个工作日内完成仓库验收；
3. 验收（ACCEPT）三向判定并生成验收单：
   - 完好 → 回库（IN_STOCK），可再次投放；
   - 可修复 → 送修（REPAIRING）；
   - 无法修复 → 报废（SCRAPPED）；
4. 验收须核对柜体编号、压缩机运行、外观与配件完整度，
   拍照归档。

## 7. 押金退还

1. 验收完成后系统生成「押金退还」任务（FREEZER_DEPOSIT_REFUND），
   流水（DEPOSIT_REFUNDED）关联验收单；
2. 验收完好或在合理使用损耗范围内的，押金全额退还；
3. 人为损坏按维修报价从押金中扣除，不足部分向商家追偿；
4. 押金退还在验收完成后 10 个工作日内办结，财务复核放款。

## 8. 常见问题（FAQ）

**Q：商家说冰柜不制冷，巡访时我该填什么状态？**
A：巡访表单冰柜状态填「破损故障（DAMAGED）」，并立即在冰柜详情页
发起报修，两者缺一不可——只填状态不保修，维修单不会生成。

**Q：店里看不到冰柜了怎么处理？**
A：表单填「现场未见（ABSENT）」并当场与商家核实；无法说明去向的
立即上报片区经理，按保管协议追究责任，必要时启动风险处置。

**Q：维修期间商家没有冰柜用，会影响陈列考核吗？**
A：系统内冰柜处于「维修中」状态的商家，当期陈列合格率考核予以豁免，
由片区经理在绩效复核时确认。

**Q：押金什么时候能退给商家？**
A：合同终止并完成冰柜撤回与仓库验收后，系统生成押金退还任务，
验收完成后 10 个工作日内退款；人为损坏按报价扣除。

**Q：冰柜维修要自己垫付费用吗？**
A：不需要。维修由签约服务商上门，费用公司统一结算；
人为损坏部分从商家押金中抵扣，员工不得私下收取维修费。
